# Discord moderation bot

Бот для нескольких серверов на Python 3.9+. Данные каждого сервера, роли администрации, списки, защита ролей и сроки банов хранятся локально в SQLite.

## Установка

1. Установите Python 3.9 или новее. В терминале откройте папку проекта и выполните:

   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и укажите `DISCORD_TOKEN`. Токен, опубликованный в переписке, скомпрометирован: сбросьте его в Discord Developer Portal и используйте новый. Не публикуйте `.env`.
3. В Discord Developer Portal → Bot включите **Server Members Intent** и **Message Content Intent**. Пригласите бота через OAuth2 с областью `bot` и правами **View Channels**, **Send Messages**, **Ban Members**, **Manage Roles**, а также **Read Message History**. Роль бота должна находиться выше ролей, которыми он управляет, и ролей участников, которых он банит.
4. Запустите `python bot.py`. Бот должен работать постоянно; после перезапуска он проверит истёкшие баны. Данные сохраняются в `moderation.db` (путь можно изменить через `DB_PATH` в `.env`). Делайте резервную копию базы, когда бот остановлен.

## Доступ

- Владелец сервера: все команды, включая назначение CEO.
- CEO: управление вайтлистом и модераторами, остальные команды модерации.
- `semi`: чёрный список, баны, защита ролей, снятие ролей и просмотр `.list`.
- `low`: снятие ролей и просмотр `.list`.
- `dope`: те же команды, что у `low`, и защита от команды `.rape` даже со стороны CEO и владельца. Эта защита не распространяется на `.aban`, чёрный список или бан через Discord. Сначала снимите существующий rape-бан, прежде чем назначать `dope`.

Обычные права администратора Discord сами по себе не выдают доступ к командам. Роль бота и права Discord также ограничивают его действия. Команды бана, чёрного списка и снятия роли нельзя применять к себе, боту, владельцу сервера, участникам вайтлиста и пользователям с равными или более высокими полномочиями; дополнительно учитывается иерархия ролей Discord. Упоминание пользователя можно заменить числовым ID.

## Команды

- `.blacklist @user/id` — добавить в чёрный список; при следующем входе пользователь будет забанен.
- `.blacklist list`, `.unblacklist @user/id` — посмотреть список или удалить запись. Удаление из списка не снимает действующий бан Discord.
- `.list` — вайтлист, CEO, модераторы и временные баны.
- `.aban @user/id дни причина` — временный бан; `.aunban @user/id` — снять его.
- `.rape @user/id дни причина` — временный бан с повторным баном при входе, если его сняли в Discord до окончания срока; `.unrape @user/id` — снять его и отменить повторный бан.
- `.unrole @user/id ID_роли` — снять роль.
- `.прота @user/id`, `.прота list`, `.анпрота @user/id` — включить, посмотреть или отключить защиту ролей.
- `.wl list`, `.wl add @user/id`, `.wl rem @user/id` — управление вайтлистом.
- `.ceo add @user/id`, `.ceo rem @user/id` — управление CEO.
- `.mod add @user/id semi/low/dope`, `.mod rem @user/id` — управление модераторами.

Срок бана — от 1 до 3650 дней. Бот проверяет истечение раз в минуту; если он был выключен, проверка выполняется после запуска. При наличии пользователя в чёрном списке истёкший временный бан не снимается автоматически. Для добавления в вайтлист сначала удалите пользователя из чёрного списка и снимите активные баны бота.

Защита запоминает текущие обычные роли и добавленные позже, затем восстанавливает снятые роли, пока бот работает и имеет права. Роли интеграций и роли выше бота восстановить нельзя. Команда `.unrole` намеренно исключает снятую роль из защиты. События, произошедшие при выключенном боте, защита автоматически не воспроизводит. Не выдавайте права CEO и модератора непроверенным пользователям.
